# 取件箱（dsh-delivery-box）· 交付文档

> 版本 **v1.0.0** · 2026-10-29 · 适用 **DSH 桌面版 0.2.x（Windows 10/11）**
> 一句话：给 DSH 左边栏加一个「取件箱」——AI 交付的文件都往里放，你按项目分类看、点开看各对话产出的文件，
> 直接预览、一键复制到剪贴板（微信 `Ctrl+V` 就能发）。

---

## 0. 先看效果

装好后左边栏「任务看板」下面多一个 **取件箱**：

- **第一级 · 分类页**：每个分类 = 一个项目（色点 + 项目名 + 件数 + 「N 个对话」+ 最新时间 + 缩略图），
  跟 DSH 自带「项目」面板一个样式。
- **点开一个分类**：才是这个项目下的文件，**按产出它的对话再分组**（哪个对话产出了哪些文件一目了然），
  顶部「← 所有分类」返回。
- 点卡片 = 预览：图片、视频（**可拖进度条**）、音频、PDF、纯文本都支持。
- **复制图片 / 复制文件** → 切到微信聊天框 `Ctrl+V` 直接发。
- **在文件夹中显示**（资源管理器里选中）/ **打开** / **删到回收站**（二次确认）。
- 面板每 5 秒自动刷新，别的会话/你自己往文件夹里丢文件也会自动出现。

## 3. 安装

### 3.1 一键安装（推荐）

1. 把 zip **解压**到任意目录（不要在压缩包里直接双击）。
2. **双击 `install.cmd`**。
3. 看窗口输出：
   - 成功会打印 ✓、装到哪里、取件箱文件夹在哪，以及「让 AI 投递」的那行命令；
   - 失败会打印中文原因（最常见：找不到 DSH_HOME / 选错 profile）。
4. **完全退出 DSH 再打开**（点托盘退出 / 任务管理器结束都行；最小化不算）。
5. 左边栏「任务看板」下面出现 **取件箱** → 装好了。

> 默认安装位置：`%USERPROFILE%\dsh-delivery-box`（插件+工具）
> 默认取件箱：`%USERPROFILE%\取件箱`（交付物都进这里）
> 安装器会先备份 profile 的 `package.json` / `pnpm-lock.yaml`（`.bak-时间戳-dsh-delivery-box`），可回滚。

### 3.1b 如果是 clone 的仓库（开发者用法）

如果这个目录是 `git clone` 下来的仓库，直接运行 `installer\install.cmd` 即可：
安装器会识别「仓库模式」，**不复制文件**，把 profile 的 node_modules 链接直接指向仓库目录。
之后改动仓库里的代码，重启 DSH 就会生效（适合边改边用）。

### 3.2 自动定位失败 / 你有多个 profile

```bat
:: 指定 DSH_HOME（就是包含 profiles 目录的那个文件夹）
install.cmd -DshHome "C:\Users\你的用户名\.dsh"

:: 指定 profile（默认 desktop；脚本会列出可用的）
install.cmd -Profile desktop

:: 改安装位置 / 取件箱位置
install.cmd -InstallDir "D:\dsh-delivery-box" -InboxDir "D:\取件箱"
```

**DSH_HOME 在哪？** 在 DSH 里问你的 AI 助手一句「`echo $env:DSH_HOME`」，
或看 DSH 安装目录旁边的数据目录；默认是 `C:\Users\你的用户名\.dsh`。

### 3.3 手动安装（一键脚本出问题时的对照）

```powershell
# 1) 把 plugin\ 复制到一个固定位置，例如 %USERPROFILE%\dsh-delivery-box\plugin
# 2) 记下 DSH profile 目录，例如 %USERPROFILE%\.dsh\profiles\desktop
# 3) 备份
Copy-Item "$profile\package.json" "$profile\package.json.bak-manual"
Copy-Item "$profile\pnpm-lock.yaml" "$profile\pnpm-lock.yaml.bak-manual"
# 4) 改 package.json：dependencies 加  "dsh-delivery-box": "link:<插件绝对路径，正斜杠>"
#    dsh.profile.bundles 数组末尾加 "dsh-delivery-box"
# 5) 改 pnpm-lock.yaml：importers → "." → dependencies 下加
#      dsh-delivery-box:
#        specifier: link:<插件绝对路径，正斜杠>
#        version: link:<profile 到插件的相对路径，正斜杠>
# 6) 建目录链接（junction）：
New-Item -ItemType Junction -Path "$profile\node_modules\dsh-delivery-box" -Target "<插件绝对路径>"
# 7) 写 plugin\inbox.config.json：{ "inboxDir": "D:\\取件箱" }
# 8) 完全重启 DSH
```

⚠️ 删链接只 `cmd /c rmdir "<链接路径>"`，**不要** `rd /s`（会跟着删到插件目录）。

### 3.4 如果你们的 DSH 有 `plugin_manager`（创造模式工具）

```text
plugin_manager 动作 install_bundle，target = <解压目录>\plugin
```
装完后手动写 `plugin\inbox.config.json`（`{"inboxDir":"D:\\取件箱"}`），再完全重启 DSH。

## 4. 装完怎么用

1. 左边栏点 **取件箱** → 第一页是「分类」。
2. **点开一个分类** → 看这个项目下各对话产出的文件（再点「← 所有分类」回去）。
3. 点文件卡片 = 预览；视频可以拖进度条、全屏。
4. 要发微信：点 **复制图片**（图片）或 **复制文件**（其它），切到微信 `Ctrl+V`。
5. 也可以 **在文件夹中显示**，从资源管理器把文件拖进微信。
6. 可选：跑一次 `tools\建桌面快捷方式.cmd`，会给桌面加「取件箱」快捷方式，并把文件夹钉到资源管理器「快速访问」。

## 5. 让 AI 每次交付都自动投进去（关键）

装完只是「有取件箱」，要让 AI 把东西放进去，得告诉它。**推荐直接写进 `AGENTS.md`**（每轮都会读到）：

```md
## 取件箱：每次交付都要放进去

任何会话产出成品（图片/视频/文档/报告/音频/压缩包…）后，必须跑：

& "<你的安装目录>\tools\投递.cmd" add <成品文件> --origin "<本会话标题或项目名>" --clip --json

- --origin：产出它的对话/项目名（面板按它分类，别省）
- --clip：顺手放剪贴板（图片→图像，微信 Ctrl+V 直接发）
- --link：大视频用（同盘硬链接，不占额外空间）
- 老文件补标注：  <安装目录>\tools\投递.cmd tag <文件名> --origin "<对话名>" --json
```

> 安装器会在 `tools\` 里生成 **`投递.cmd`**（里面写死了本机 node 的绝对路径），所以**不需要**node 在 PATH 里。
> 如果没生成（脚本提示没找到 node），把那行换成 `node "<安装目录>\tools\inbox.mjs" add ...`。

### 5.1 命令行工具 `inbox.mjs` 用法

```text
投递.cmd add <文件> [--name "新名字"] [--clip] [--reveal] [--link] [--origin "对话"] [--project "项目"] [--json]
投递.cmd list [--json]
投递.cmd copy [名字|latest] [--mode auto|image|file] [--json]
投递.cmd reveal [名字|latest]
投递.cmd tag [名字|latest] --origin "对话" [--project "项目"] [--json]
投递.cmd open
```

- `add`：复制到取件箱（重名自动 `-2`），入库时间=现在（列表按它倒序）。
- `--link`：同盘硬链接，视频不占额外空间；跨盘自动退回复制。
- `--clip`：图片进图像剪贴板、其它进文件剪贴板。
- 全部命令失败会返回非 0 退出码 + 明确原因（`NOT_FOUND`/`IS_DIR`/`NOT_IMAGE`/`BAD_NAME`/`EMPTY`）。

## 6. 取件箱文件夹在哪、怎么改

- 默认：`%USERPROFILE%\取件箱`（即 `C:\Users\你的用户名\取件箱`）。
- 改位置：编辑 `<安装目录>\plugin\inbox.config.json`：

```json
{ "inboxDir": "D:\\取件箱" }
```

然后**完全重启 DSH**。也可以不写文件，直接设环境变量 `DSH_INBOX_DIR`（优先级最高，适合临时换）。

- 想换目录但保留已有文件：改路径后把旧文件夹里的文件拷过去即可（`.origins.json` 是隐藏的来源标注文件，一起拷过去分类才不会丢）。

## 7. 卸载

1. 双击 **`uninstall.cmd`**（或 `install.cmd -Uninstall`）。
2. 它会：从 profile 的 `package.json` 删依赖和 bundle、从 `pnpm-lock.yaml` 删条目、删 node_modules 里的 junction。
3. 完全重启 DSH，侧栏图标消失。
4. 插件目录（`%USERPROFILE%\dsh-delivery-box`）和取件箱里的文件**不会删**，想清干净手动删。

## 8. 常见问题

**Q：装完侧栏没有「取件箱」？**
1. 是不是只最小化了？要**完全退出 DSH** 再开。
2. `install.cmd` 是不是选错了 profile？（重跑并看输出的 profile 路径，或 `-Profile <名字>`）
3. 打开 `<profile>\package.json`，看 `dsh.profile.bundles` 最后有没有 `"dsh-delivery-box"`、`dependencies` 里有没有 `"dsh-delivery-box": "link:..."`。
4. 插件版本和 DSH 差太多（0.1.x）→ 找我要适配版。

**Q：面板是空白的？**
- 打开的是空取件箱的话会显示「取件箱还空着」，正常。
- 真报错：把 DSH 的开发者控制台（应用菜单 → 开发者工具，如果有）里红色报错发我。

**Q：视频不能拖进度条？**
- v1.2 已修（媒体走本机 HTTP + Range 请求）。如果还拖不动，可能你的 DSH 把页面协议改了，把版本号告诉我。

**Q：复制图片失败？**
- svg / avif 不能进 Windows 图像剪贴板 → 用「复制文件」或「打开」。
- 剪贴板被别的程序占用时重试一次即可（工具有 3 次重试）。

**Q：`投递.cmd` 说找不到 node / 一运行就闪退？**
- 重跑一次 `install.cmd`（会重新探测 node 并重写 `投递.cmd`）。
- 或手动换成：`node "<安装目录>\tools\inbox.mjs" ...`（node 在 PATH 里就行）。

**Q：DSH 更新后取件箱没了？**
- 更新若重置了 profile 配置，重跑 `install.cmd` 即可；取件箱里的文件不受影响。

**Q：Windows 提示「此应用无法在你的电脑上运行 / 脚本被禁止」？**
- `install.cmd` 内部用 `-ExecutionPolicy Bypass` 启动 PowerShell，不走系统脚本策略。如果还被拦截，
  用「右键 install.ps1 → 使用 PowerShell 运行」或在 PowerShell 里：
  `powershell -ExecutionPolicy Bypass -File .\install.ps1`。

## 9. 安全与隐私

- 插件的 Host 半边只在**本机回环**的 DSH Web 服务上注册 7 条接口（list / file / copy / reveal / open / delete / open-folder），**没有鉴权**，
  任何本机程序理论上都能调用。**不要把 DSH 的 Web 端口（或 remote-web-ui 隧道）直接暴露到公网。**
- 插件只读写你的取件箱目录、剪贴板、资源管理器选中；**删除是删到回收站**，不硬删。
- 不联网、不上传任何文件。
